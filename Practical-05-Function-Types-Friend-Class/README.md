# Practical 5: Function Types, Friend Class

## Program: List Class

**Aim:** To implement a list in C++ and demonstrate forward and backward traversal.

**Language:** C++

**Header Files:** `iostream`, `list`

## Concepts Used
- STL list container
- `push_back()`
- Forward traversal
- Reverse iterators

## Expected Output
```text
Forward traversal: 10 20 30
Backward traversal: 30 20 10
```

## How to Run
Compile `list_class.cpp` using a C++ compiler and execute the program.
