# SY OOP Practical 10: Templates

## Aim
To implement function templates and class templates in C++.

## Programs
1. `function_template.cpp` – Adds integer, float, and double values using a function template.
2. `class_template.cpp` – Performs addition and multiplication using a class template.

## Language
C++

## Header File
`iostream`

## Sample Output

### Function Template
```text
Integer Addition
30
Float Addition
10.8
Double Addition
52.9
```

### Class Template
```text
Integer addition: 30
Integer multiplication: 200
Double addition: 6.5
Double multiplication: 10
```

## How to Run
Compile each `.cpp` file using a C++ compiler and execute it.
