 # Practical 7: Polymorphism

## Aim
To implement runtime polymorphism in C++ using virtual functions and function overriding.

## Problem Statement
To demonstrate polymorphism using a base class `Payment` and derived classes `Credit` and `Upi`.

## Programming Language
C++

## Header File
- `iostream`

## Concepts Used
- Runtime polymorphism
- Inheritance
- Virtual functions
- Function overriding
- Base-class pointers

## Program
`polymorphism.cpp`

## Sample Output
```text
Make a credit card payment
Make a Upi payment
Make a general payment
```

## How to Compile and Run
Compile using a C++ compiler:

```bash
g++ polymorphism.cpp -o polymorphism
```

Run the generated executable. On Windows, use `polymorphism.exe`.

## Conclusion
Runtime polymorphism was demonstrated successfully using virtual functions and overridden methods in the `Payment`, `Credit`, and `Upi` classes.
