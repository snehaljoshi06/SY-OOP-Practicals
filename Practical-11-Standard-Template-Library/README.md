
# Practical 11 – Standard Template Library (STL)

## Aim
To implement list and vector containers of the C++ Standard Template Library.

## Part A – List
Demonstrates:
- push_back()
- push_front()
- pop_front()
- pop_back()
- size()
- sort()
- reverse()
- remove()
- Iterators

## Part B – Vector
Demonstrates:
- push_back()
- size()
- front()
- back()
- insert()
- erase()
- sort()
- pop_back()
- at()
- clear()

## Header Files
- iostream
- list
- vector
- algorithm

## Sample Input
10 20 30

## Compile and Run
g++ stl_list_vector.cpp -o stl_list_vector

./stl_list_vector

## Result
Successfully implemented list and vector containers using C++ STL and demonstrated their different operations.
