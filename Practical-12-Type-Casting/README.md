
# Practical 12 – Type Casting in C++

## Aim
To demonstrate type casting and casting operators in C++.

## Programs

### 1. Dynamic Casting
File: dynamic_casting.cpp

Demonstrates:
- Base and derived classes
- Virtual functions
- Runtime polymorphism
- dynamic_cast operator
- Runtime type checking

### 2. Type Casting
File: type_casting.cpp

Demonstrates:
- Implicit type casting
- Explicit type casting
- static_cast operator
- Conversion between integer and floating-point values

## Header Files
- iostream

## Sample Input
No input required.

## Compile and Run

Dynamic Casting:
g++ dynamic_casting.cpp -o dynamic_casting
./dynamic_casting

Type Casting:
g++ type_casting.cpp -o type_casting
./type_casting

## Result
Successfully demonstrated implicit and explicit type casting and runtime dynamic casting using C++.
